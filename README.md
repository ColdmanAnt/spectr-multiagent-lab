# СПЕКТР — четыре лабораторные работы

Многоагентная система управления вымышленной исследовательской лабораторией. Научные группы конкурируют за измерительные установки, роботы доставляют контейнеры, участники договариваются об очереди, а контроль качества проверяет обязательства и результаты.

**Каждая папка самостоятельна:** содержит свои исходники, сервер, CLI, тесты, данные и отчёт. Для её запуска соседние лабораторные не нужны. В работах используется одна и та же исходная модель агентов, чтобы сохранять сопоставимость исследований; код модели включён в каждую папку.

Требуется **Node.js 20 или новее**. Все команды используют стандартную библиотеку; установка пакетов, ключи и внешние сервисы не нужны. Ресурсы и время условны; реальные ядерные процессы не моделируются.

## Веб-интерфейсы

Из корня репозитория:

```sh
node Lab1/server.mjs
node Lab2/server.mjs
node Lab3/server.mjs
node Lab4/server.mjs
```

Каждую команду запускают в отдельном терминале. Адреса:

| Работа | Адрес |
| --- | --- |
| Lab1 | http://127.0.0.1:4171 |
| Lab2 | http://127.0.0.1:4172 |
| Lab3 | http://127.0.0.1:4173 |
| Lab4 | http://127.0.0.1:4174 |

Можно открыть только нужную работу. Например, `cd Lab2`, затем `node server.mjs`. Другой порт задаётся аргументом `--port 8080`.

Для размещения на своём HTTP-сервере достаточно содержимого `dist/` выбранной лабораторной. Сборка не требуется. Встроенные серверы слушают `127.0.0.1`; для внешнего доступа можно использовать статический хостинг или обратный прокси. Открытие `index.html` двойным щелчком не поддерживается: ES-модули загружаются через HTTP.

## Демонстрации и исследования

```sh
node Lab1/main.mjs demo
node Lab2/main.mjs demo --allocation central
node Lab2/main.mjs demo --allocation contract
node Lab3/main.mjs demo
node Lab3/main.mjs demo --no-negotiation
node Lab4/main.mjs demo --scenario device
node Lab4/main.mjs demo --scenario device --no-protection
```

Повторение исследований:

```sh
node Lab2/main.mjs experiment
node Lab3/main.mjs experiment
node Lab4/main.mjs experiment
```

Lab2 выполняет 40 прогонов сравнения распределения; Lab3 — 80 прогонов сравнения переговоров; Lab4 — 800 прогонов с пятью сценариями и двумя состояниями защиты. По умолчанию используются seed 1–20 и горизонт 180 тактов. Одинаковый seed задаёт одинаковую нагрузку.

Команды можно выполнять и из соответствующей папки, убрав префикс `LabN/`. Результаты сохраняются внутри этой лабораторной независимо от текущей папки терминала. Справка и детали методики приведены в README каждой работы.

## Проверки

В каждой папке:

```sh
npm test
```

Для проверки одной работы достаточно скопировать только её папку и выполнить ту же команду. Тесты проверяют воспроизводимость, протоколы, сохранение ресурсов и кредитов, защиту результатов, аналитику и отдельный запуск лабораторной.

В отчётах находятся постановка задачи, методика, результаты и выводы. Исходный код и полные трассы предоставлены в папках работ отдельно от отчётов.
