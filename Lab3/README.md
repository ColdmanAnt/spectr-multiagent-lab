# Lab3 — Переговоры и разрешение конфликтов

Сравнение поведения научных групп до и после включения переговоров об очереди.

Самостоятельная работа: все необходимые исходники и данные находятся в этой папке, зависимостей от других Lab нет. Требуется Node.js 20 или новее; сторонние пакеты не используются.

## Веб-интерфейс

```sh
node server.mjs
```

Откройте **http://127.0.0.1:4173**. Из корня репозитория можно выполнить `node Lab3/server.mjs`. Порт меняется через `--port 8080`. Для статического размещения скопируйте содержимое `dist/` на свой HTTP-сервер; сборка не нужна.

Доступны два механизма распределения и переключатель переговоров. Сценарий штатный, защита включена. Быстрая серия в интерфейсе использует 12 seed и четыре сочетания настроек.

Изменение настроек начинает новую смену. Кнопки «Один такт» и «+10 тактов» позволяют разобрать решения. Полная трасса JSON выгружается из журнала. Карточка исследования показывает фактическую историю образца.

## Командная демонстрация и результаты

```sh
node main.mjs demo
node main.mjs demo --no-negotiation
node main.mjs experiment
```

Из корня репозитория добавьте перед `main.mjs` префикс `Lab3/`. Выходные пути считаются от папки работы, поэтому результаты попадут сюда при запуске из любого каталога. Команда `demo` сохраняет файл с параметрами в имени в `results/demo/` и не меняет формальные трассы исследования. Справка: `node main.mjs --help`.

Основная серия: 20 seed × 2 механизма × 2 режима переговоров = 80 прогонов. Анализируются полезность, завершения, ожидание, сообщения, индекс Джейна и сохранение ресурсов. В трассах видны OFFER, COUNTER, ACCEPT, REJECT, реальные обмены очередью и переводы кредитов.

Таблицы отдельных прогонов, сводка и параметры хранятся в `results/reliability/`. Повторный эксперимент заменяет эти файлы. Средние и выборочные стандартные отклонения считаются по сменам; отдельные задачи не являются независимыми повторностями.

## Тесты

```sh
npm test
```

Можно скопировать эту папку отдельно и проверить её той же командой. Состояние симуляции воспроизводится при одинаковых параметрах и seed. Скорость отображения не меняет условное время модели.

## Отчёт и исходники

- [PDF](report.pdf) и [Word](report.docx) — отдельный отчёт лабораторной.
- `dist/engine.js` — явные правила агентов, распределения, переговоров и проверки результатов.
- `dist/analytics.js` — оценки текущей очереди и история образцов.
- `dist/lab-config.js` — профиль этой работы и доступные элементы управления.
- `dist/app.js`, `dist/index.html`, `dist/style.css` — интерфейс.
- `main.mjs` — командный запуск демонстрации и применимых исследований.
- `tests/` — проверки модели и автономного запуска.
- `results/` — экспериментальные приложения к отчёту.

Это дискретная учебная модель вымышленной лаборатории. Все длительности и ресурсы условны; реальные ядерные процессы не моделируются.
